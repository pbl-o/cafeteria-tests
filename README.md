# Soft-jobs-API

Ejercicio de testing unitario a una API REST con
JEST y el paquete supertest.

## Tecnologías Empleadas

- Node.js, express.js, jest

## Instalación y uso.

Instrucciones des instalación y configuración del proyecto:

1. Clonar repositorio:

```bash
git clone https://github.com/pbl-o/cafeteria-tests.git
```

2. Instalar dependencias:

```bash
npm install
```

3. Para ejecutar el test, utilizar el siguiente comando:

```bash

npm run test

```
